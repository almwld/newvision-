# Contributing

1. Run `flutter analyze` and `flutter test`.
2. Run Android unit tests and a debug build.
3. Keep domain contracts stable and avoid moving camera processing into Flutter.
4. Do not commit MediaPipe model binaries, keystores, passwords or API credentials.
5. Keep commits focused by phase and include tests for behavioral changes.
6. Document public native APIs with KDoc and keep Dart code compatible with the repository lint rules.
