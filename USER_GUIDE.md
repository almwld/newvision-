# User Guide

1. Open NewVision and complete onboarding.
2. Grant Camera, Overlay and Accessibility permissions.
3. Run the nine-point calibration.
4. Start eye tracking.
5. Keep your eyes open for normal cursor movement; blinking freezes the cursor.
6. Hold your gaze on a target for the configured dwell duration to activate a click.
7. Change dwell duration or clear calibration from Settings.

All vision processing is local to the device.
