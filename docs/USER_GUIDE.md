# NewVision — دليل المستخدم

## البدء
1. افتح التطبيق وأكمل التعريف الأولي.
2. امنح الكاميرا، والعرض فوق التطبيقات، وإمكانية الوصول.
3. نفّذ المعايرة ذات التسع نقاط.
4. ابدأ التتبع.

## المعايرة
اتبع النقطة على الشاشة دون تحريك الرأس. تُعالج بيانات العين محلياً.

## التحكم
يحرك مؤشر العين على الشاشة. التثبيت على موضع لفترة التثبيت المحددة ينفذ النقر، بينما يوقف الرمش التثبيت مؤقتاً.

## الإيقاف
استخدم زر الإيقاف الفوري أو أوقف الكاميرا من الإعدادات.
